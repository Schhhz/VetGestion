\# VetGestión



Sistema de gestión veterinaria desarrollado en Python como proyecto académico para el curso Lenguajes de Programación (UAIN1288P).



\## Descripción



VetGestión permite organizar el registro de propietarios, mascotas y atenciones veterinarias mediante una aplicación de consola.



\## Funcionalidades



\- Registro de propietarios.

\- Registro de mascotas vinculadas a sus propietarios.

\- Registro de citas y motivos de atención.

\- Asignación automática de veterinarios disponibles.

\- Gestión de pacientes en espera mediante orden de llegada (FIFO).

\- Finalización de atenciones y liberación de veterinarios.

\- Consulta de registros.

\- Persistencia de información mediante archivos JSON.



\## Tecnologías utilizadas



\- Python.

\- Programación orientada a objetos.

\- Programación funcional: map, filter y reduce.

\- JSON para persistencia de datos.

\- unittest para pruebas.



\## Ejecución



```bash

py VeterinariaLimaVet.py

```



\## Pruebas



```bash

py -m unittest test\\\\\\\_vetgestion -v

```



\## Consideraciones



Este proyecto es un prototipo académico. No debe utilizarse con datos personales reales sin implementar previamente medidas de seguridad y protección de datos adecuadas.
